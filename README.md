## 📌 About the Project

This repository contains the official presentation website for Team **Haxtrea** participating in **Smart India Hackathon 2026**.

The website is designed as a cinematic, product-launch style presentation website following the exact 6-section structure required by the official SIH evaluation guidelines:
1. **Title Page** — Team & Problem Statement Introduction
2. **Proposed Solution** — RAG architecture & local inference overview
3. **Technical Approach** — Step-by-step 7-stage RAG pipeline, interactive smartphone mockup demonstration, and camera scan concept
4. **Feasibility & Viability** — Technical feasibility, challenges & risk mitigation analysis
5. **Impact & Benefits** — Target audience impact & quantifiable key benefits
6. **Research & References** — Foundational standards and literature sources

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Animations:** GSAP 3.15 + ScrollTrigger + ScrollToPlugin
- **Design System:** Custom Dark Mode CSS Design Tokens (`#050505` base, Apple-inspired minimalism)
- **Typography:** Inter & JetBrains Mono

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js installed (v18+ recommended).

### Installation

```bash
# Clone the repository
git clone https://github.com/fultric/<REPO_NAME>.git
cd presentation

# Install dependencies
npm install
```

### Development Server

```bash
npm run dev
```

Visit `http://localhost:5173/` (or port indicated in terminal) in your browser.

### Production Build

```bash
npm run build
npm run preview
```
